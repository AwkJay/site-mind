WHAT TO ADD TO MANAK (in priority order — each maps to a real commissioning check
the pillar needs; add the digitised verbatim text, not a summary, same as clauses.json)
------------------------------------------------------------------------------------

1. CEA (Measures relating to Safety and Electric Supply) Regulations, 2010
   — governs LV/HV installation, testing, and commissioning safety requirements.
   Highest priority: this is the umbrella electrical-safety regulation everything
   else sits under.

2. IS 3043:1987 — Code of Practice for Earthing
   — earth-pit resistance values, earthing-conductor sizing, testing acceptance
   criteria. Needed for the DRUPS/switchgear/UPS earthing commissioning checks.

3. IS 732:2019 — Code of Practice for Electrical Wiring Installations
   — LV wiring installation and pre-commissioning test requirements (insulation
   resistance, continuity, polarity).

4. NBC 2016 Part 4 (Fire and Life Safety) — fire detection/suppression system
   commissioning and acceptance testing clauses.

5. NBC 2016 Part 8 (Building Services), Section 2 (Electrical and Allied
   Installations) — DC-relevant electrical services commissioning (switchgear,
   transformers, standby power).

6. DG-set testing/acceptance standard — candidate: IS 8623 (Low-voltage
   switchgear and controlgear assemblies) for switchgear FAT/SAT, or the CPCB
   DG-set emission/noise norms if the check is emissions-compliance rather than
   electrical performance. Confirm exact scope with the user before citing —
   don't guess which one the pitch needs.
