Sheet 01 — Thesis

The LLM never decides

The one sentence to remember if you remember nothing else.

  • Every pass/fail is a deterministic Python threshold, evaluated against a real, verbatim clause.
  • The LLM is handed the clause and the decision after it's already made — it only writes the explanation.
  • Result: a hallucination rate you can actually measure and publish, not a "trust me."

Top to bottom: the decision (highlighted box) is made before the LLM ever runs.

Why this is harder, not easier Building real retrieval + real threshold logic costs more than hoping a model gets it right — the payoff is a decision you can audit, not just a plausible-sounding one.

Sheet 05 — Honesty model

The actual moat

  • Never invent a clause. Every citation resolves to real fetched text, never paraphrased from memory.
  • Decisions in Python, not the LLM — restated because it's load-bearing.
  • No asserted numbers. Every metric shown is a real computed run, re-checkable live.
  • No ML training anywhere. AI engineering — retrieval + deterministic logic — not a trained model.

Citation trust tiers — stamped, not blended

codebook_verified the gold standard, via the Codebook pipeline.

primary_native_pdf real doc, clean current PDF, no OCR risk.

primary_scan_ocr real doc, older scan — OCR + edition caveats.

cross_source_unverified compiled from secondary sources, primary is paywalled (e.g. ASHRAE).

Real vs representative

  • Real: every clause citation, the decision logic, all 21 evals, document ingestion, CPM recomputation.
  • Representative: DC1's project, documents, RFIs, and schedule are synthetic — modelled on real public Indian DC tenders, disclosed as such.
