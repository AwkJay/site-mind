13 / 16Technical ExcellenceScalability
Architecture — where we are (and aren't) agentic

Agentic where options are grounded, never where a check is binary

  • The LLM only ever writes prose — every arrow into it labelled "prose only"
  • manak is a build-time dependency, not a live one
  • Agentic where a task is naturally multi-option and every option is a grounded computation (schedule mitigation)
  • Never agentic where a task is a single verifiable yes/no against a cited standard (compliance, commissioning, cost-risk)

The honest answer to "why not a fully agentic platform" — a stated position, not a dodge.
